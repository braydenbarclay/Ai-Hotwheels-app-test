# Hot Wheels Collection PWA

Mobile-first PWA starter for a personal Hot Wheels collection.

## Current build
- iPhone camera capture
- Choose a package photo
- Save the photo with car metadata
- Search collection
- Collection grid
- Detail view and delete
- PWA manifest/service worker
- Local persistence in browser storage

## Next connection layer
- Supabase authentication/database/storage for cloud sync
- Vision AI endpoint for automatic Hot Wheels identification
- Multiple package variants grouped under one casting

## Run locally
Serve this folder over HTTPS (or localhost) because camera access requires a secure context. For iPhone use, deploy it to a HTTPS host, then use Safari > Share > Add to Home Screen.
